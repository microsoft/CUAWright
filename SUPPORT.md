# Support

Use [GitHub Issues](https://github.com/microsoft/Webwright/issues) for reproducible
bugs and feature requests. Search existing issues first. Include the CUAWright
version, operating system, command shape with secrets removed, and the smallest
reproduction you can share.

Do not post API keys, endpoint URLs, proxy configuration, gated task contents,
evaluator details, or private run artifacts. Security vulnerabilities should be
reported through the process in [SECURITY.md](SECURITY.md), not a public issue.

## Microsoft Support Policy  

This project is provided as open-source software without Microsoft Customer
Service and Support coverage. Support is limited to the community resources above.
