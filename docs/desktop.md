# CUAWright desktop

`cuawright desktop` (also available as `cuawright-desktop`) runs one official OSWorld-V2 Linux task using a persistent
terminal Actor in an Ubuntu Docker VM. It preserves the imported release's
prompts, standard Responses API requests, submission controls, shared call budget,
compaction, proxy handling, evaluation, and multi-phase lifecycle.

## Install

Use Python 3.12 or newer:

```bash
pip install -e ".[desktop]"
cuawright-desktop --help
```

Provision OSWorld externally. Supported source: **OSWorld-V2 v2026.08.08**, commit
`d578d2d4e0dc82b43e270fdaa7fa89d9708cd154`. The source checkout must be clean.
The interpreter running CUAWright must also have the official OSWorld dependencies
installed. Docker, the VM, Linux V2 task classes, task assets, websites, and any
required proxy must already be provisioned; execution does not download or repair them.

The API credential file must contain one key, belong to the invoking user, and
have mode `0600`. Keep it outside the source, task, asset, and result directories.
Use a new result directory whose parent already exists.

## Run

```bash
cuawright-desktop \
  --source /absolute/path/to/OSWorld-V2 \
  --tasks /absolute/path/to/tasks \
  --assets /absolute/path/to/assets \
  --vm /absolute/path/to/Ubuntu.qcow2 \
  --credentials /absolute/path/to/api-key \
  --results /absolute/path/to/results/task-001 \
  --task-id 001 --model YOUR_MODEL --reasoning high
```

For task-requested proxies, supply `--proxy-config /absolute/path/to/proxy.json`.
`--base-url` selects a user-supplied Responses-compatible endpoint.
Only standard Responses API fields are sent. The default budget is 300 model calls; compaction
occurs every 40 calls. One invocation owns one task; batch scheduling stays external.

Commands execute inside the guest VM. Screenshot, simulated-user, and submission
controls remain under `/opt/cuawright-tools/`. Submission triggers official
evaluation; a plain final answer does not substitute for explicit submission.
Task 069's phases share one model-call budget.

## Artifacts and validation

Each run writes `manifest.json`, `trace.jsonl`, and `result.json`, plus screenshot
artifacts. Setup, transport, evaluation, persistence, and cleanup failures are explicit.
Evaluator payloads, hidden task state, and credentials are excluded from diagnostics.

```bash
pip install -e ".[desktop,test,build]"
pytest -q tests/unit release/osworld/tests
python -m build --wheel
```

Wheels include unified runtime provenance, generated by `setup.py` without editing
the source tree. The combined package retains the MIT browser license and the
Apache-2.0 imported desktop license; see `NOTICE` and `licenses/`.

The supported external OSWorld source is available at
<https://github.com/xlang-ai/OSWorld-V2>. API keys and custom endpoint URLs must
be supplied locally; credentials, proxy configuration paths, and endpoint URLs
are excluded from saved public settings.
